# Independent Multiplayer RPG Systems Platform

## Overview

I built and operated a long-running independent multiplayer RPG systems platform for 10+ years. The project became a long-term technical sandbox for live operations, gameplay scripting, custom UI, progression systems, web/community operations, promotional media, and player support.

This case study focuses on original systems, scripting, UX, content workflows, community support, and technical problem-solving. It intentionally avoids raw scripts, server details, private player data, and sensitive implementation materials.

## Role

Founder, Systems Developer, UI Developer, Live Operations Lead

- UX Engineer
- Frontend / Interactive Developer
- Implementation Engineer
- Technical Designer
- Game Systems Designer
- Live Operations Coordinator
- Tools / Platform Support

## Context

The goal was to create a custom multiplayer RPG experience with a complete progression path, original systems, custom UI, story choices, dungeons, bosses, seasonal updates, and a live community. The challenge was to turn a heavily customized game environment into a cohesive player-facing product with real users and long-term operational needs.

## What I Built

- A custom leveling experience across roughly 10 zones.
- 100+ custom quests.
- Custom NPCs, creatures, loot tables, items, story beats, dungeons, raids, bosses, and finale outcomes.
- Item upgrade system with chance-based outcomes, upgrade stones, success/failure states, and stat progression.
- Achievement system with custom UI, triggers, rewards, and progression feedback.
- Choose-your-path system with light/dark decisions and multiple finale outcomes.
- Custom ability system with unlockable abilities, progression points, limits, and player build choices.
- Hundreds of custom spells and abilities.
- Player feedback UI that responds to choices and in-game behavior.
- Out-of-bounds and anti-breakage handling to reduce player-facing bugs.
- Seasonal content updates with event-specific achievements and rewards.

## Technical Work

- Lua scripting for gameplay systems, UI, quest behavior, and player-facing features.
- SQL work for content, items, quests, creatures, loot tables, progression state, and system configuration.
- TrinityCore compilation and update workflows using Visual Studio.
- Web portal support and customization using a CMS-based community portal.
- Dedicated server hosting, website hosting, community setup, and live support operations.
- Blender and asset tooling for adapting, rigging, importing, and configuring models, weapons, characters, maps, and cinematic assets.

## Live Operations

- Maintained the platform across a 10+ year lifecycle.
- Managed website updates, server upkeep, player communication, community operations, bug fixes, performance tuning, and seasonal content.
- Recruited and managed community support contributors.
- Created announcements, trailers, public updates, installation instructions, and community-facing support workflows.

## Media And Launch Work

- Produced promotional trailers and launch media using Adobe Premiere Pro, Photoshop, After Effects, Blender, and in-game capture workflows.
- Created one legacy trailer approaching 500K views.
- Created recent trailers reaching tens of thousands of views.
- Produced cinematic/3D animation work in Blender for launch promotion.

## Outcomes

- 10+ years maintained.
- 10K+ registered users.
- 1.35M+ cumulative website views.
- 100+ quests.
- Hundreds of custom spells and abilities.
- Roughly 10-zone custom progression world.
- Long-running community and live operations process.
