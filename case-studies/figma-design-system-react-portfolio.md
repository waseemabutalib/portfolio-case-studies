# Figma Design System and React Portfolio

## Overview

I created design system and web presentation work using Figma, React, JavaScript, HTML/CSS, Tailwind, and responsive UI practices. This case study shows how I think about components, states, accessibility, layout, user flows, and implementation-ready design.

## Target Roles This Supports

- UX Engineer
- Frontend Developer
- Web Developer
- Design Engineer
- Product Designer with technical implementation skills

## Projects Represented

- Figma component library and interface design work.
- React portfolio site.
- UX strategy, wireframes, and high-fidelity prototypes for client-facing web projects.
- Usability studies, heuristic evaluations, and analytics-informed design improvements.

## Figma Design System Work

Key evidence:

- 100+ reusable UI components.
- Auto-layout structures.
- Interactive states.
- Accessible color tokens.
- Responsive wireframes.
- Scalable web prototyping.

The work focused on making design decisions reusable, consistent, and easier to translate into implementation. This included thinking through component states, layout behavior, navigation patterns, visual hierarchy, and interaction flows.

## React Portfolio Work

Key evidence:

- React portfolio site.
- Custom CSS transitions.
- Media-rich project presentation.
- Interactive lightbox components.
- Project pages for creative and technical work.

The portfolio work connected visual presentation with frontend implementation. It gave me practice structuring project data, presenting media-rich work, building interactive components, and designing responsive pages for different screen sizes.

## UX Process

Relevant process:

1. Define the user or stakeholder need.
2. Map content and interaction flow.
3. Create wireframes.
4. Build high-fidelity prototypes.
5. Use components and reusable design patterns.
6. Review with stakeholders or users.
7. Iterate based on usability, clarity, accessibility, and implementation needs.

## Outcomes

- Built reusable component systems that support scalable prototyping.
- Connected design work to frontend implementation.
- Created web experiences that communicate projects through media, interaction, and structured information.
- Developed practical UX evidence for roles that sit between design and engineering.
