# Public Sharing And Privacy Notes

This repository is designed as public portfolio proof. It is not a backup of full project source files.

## Safe To Include

- Sanitized case study text.
- Public-safe metrics.
- Approved screenshots.
- High-level architecture notes.
- General workflow descriptions.
- Pseudocode or recreated examples made specifically for public sharing.

## Not Included

- Raw private code.
- Raw Lua scripts.
- Full client project folders.
- Full Omeka S theme files.
- UH internal materials.
- Client-private research/data.
- Databases or database exports.
- Credentials, server configs, API keys, or deployment secrets.
- Private messages or contact details.
- Player/account data.

## Sharing Approach

Some of my strongest projects involve client archives, private platform code, or live systems. I keep those repositories private, but I can share sanitized walkthroughs, architecture notes, screenshots, and selected code excerpts when appropriate.
